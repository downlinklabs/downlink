# downlink

Test, measure and operationalize critical user paths with tools you're already using.

Synthetic testing is one of the most valuable assets in your operational toolbox. Downlink is here to help you
increase your footprint, and get the tests closer to your infrastructure. Write playwright tests for your applications,
run them in your cluster, monitor them with your tools, as often as you want, for pennies on the dollar.

- Wire playwright tests into your gitops workflows
- Run tests on a POSIX cron schedule, on demand, or event driven.
- Pull metrics into your prometheus compatible or OTLP backend.
- Define SLOs on critical user paths based on those metrics
- Quarantine flaky tests, debug failures with screenshots and trace view.
- Annotate tests with service names, teams and more.
